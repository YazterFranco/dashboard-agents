Mira a tus agentes trabajar, en vivo

AgentDash escucha los hooks de cada plataforma y te enseña qué agente está activo, qué herramienta usa ahora mismo, sus subagentes y los Powers o servidores MCP que toca. Cómo se usa

Son cuatro pasos y solo se hacen una vez. Todos los comandos se ejecutan desde la carpeta del repo.

  1. 1

    Clona y compila

    Necesitas Node.js 22.13 o superior. Docker es opcional.

    git clone https://github.com/YazterFranco/dashboard-agents.git
    cd dashboard-agents && npm install && npm run build
  2. 2

    Levanta el dashboard

    Con Docker queda corriendo en segundo plano y guarda el historial en un volumen. Sin Docker, déjalo abierto en una terminal. Después abre http://127.0.0.1:4820.

    docker compose up -d --build
    npm run agentdash -- start
  3. 3

    Conecta tus agentes

    El instalador copia el hook a ~/.agentdash/hook.mjs, guarda un .bak de cada archivo que toca y se puede ejecutar varias veces sin duplicar nada.

  4. 4

    Trabaja como siempre

    Abre una sesión nueva de tu agente. En cuanto lea un archivo o ejecute un comando aparece en la oficina, y cada herramienta queda en su timeline. ¿Sin agentes a mano? Lanza la misma demo de esta página contra tu dashboard:

    npm run agentdash -- demo
No uses npx agentdash. En npm existe un paquete público con ese nombre que no tiene relación con este proyecto: fuera del repo, npx lo descargaría y lo ejecutaría. Usa npm run agentdash -- … o enlázalo una vez con npm link -w @agentdash/cli.

Qué pasa por dentro

Cada vez que tu agente hace algo, la plataforma ejecuta el hook. El hook reenvía el evento y termina al instante, así que tu agente no espera ni se entera si el dashboard está apagado.

Tu agenteClaude Code o Kiro dispara un hook: PreToolUse, Stop…
→
hook.mjsLee el JSON del evento, lo envía en 500 ms como máximo y sale con 0. Nunca escribe en stdout.
→
Servidor localEn 127.0.0.1:4820: traduce cada plataforma a un evento común, redacta secretos y guarda 7 días en SQLite.
→
Esta UIRecibe los cambios por WebSocket y redibuja la oficina, los flujos y el timeline.
EstadoCuándo aparece
● TrabajandoLlega un prompt o el agente empieza una herramienta (UserPromptSubmit, PreToolUse).
● Esperando inputEl agente terminó su turno o pide un permiso (Stop, Notification, AgentStop).
● ErrorLa última herramienta falló (código de salida distinto de 0 o is_error). Se mantiene hasta el siguiente prompt o herramienta.
● TerminadoLa sesión cerró (SessionEnd) o el subagente devolvió su resultado.
● InactivoNo llegó ningún evento en 10 minutos, por ejemplo si cerraste la terminal de golpe.

Preguntas frecuentes

¿Qué pasa si el dashboard está apagado?

Nada. El hook intenta enviar el evento durante medio segundo como máximo, se rinde en silencio y sale con código 0. Tu agente sigue trabajando exactamente igual.

¿Mis prompts y comandos salen de mi máquina?

No. El servidor escucha solo en 127.0.0.1 y únicamente acepta peticiones locales, así que una web que visites no puede leerlo. Antes de guardar, redacta patrones de secretos (claves sk-…, ghp_…, AKIA…, Bearer, password=) y recorta cada payload a 8 KB.

¿Cómo distingue un Power de Kiro o un MCP de Claude?

Por el nombre de la herramienta. En Claude, mcp__github__create_issue es el MCP «github» y mcp__plugin_x_… es un plugin. En Kiro, @powers/stripe/search_docs o stripe___search_docs es el Power «stripe». Cada uno aparece como etiqueta en el agente.

¿Funciona con varias sesiones en la misma carpeta?

Sí. Claude manda su propio id de sesión. Para Kiro, el hook identifica el proceso del agente saltándose la shell que lo lanza, así que dos Kiro en el mismo proyecto aparecen por separado.

Algo de Kiro aparece como «evento no reconocido». ¿Qué hago?

Los hooks de Kiro cambian entre versiones. Ejecuta npm run agentdash -- export-fixtures --platform kiro, revisa que no haya datos privados y comparte esos archivos: con ellos se ajusta el adaptador y se añaden como tests.

¿Cómo lo desinstalo?

npm run agentdash -- uninstall claude (o kiro-cli, kiro-ide). Quita solo las entradas de AgentDash y deja intactos tus otros hooks. La carpeta ~/.agentdash con el historial se conserva por si la quieres.
